# KasBon Backend Application

A robust backend application for managing debt transactions and user authentication built with Node.js, Express, and PostgreSQL.

## 🚀 Features

- User Authentication (Register, Login, Logout)
- Debt Management System
- Admin Dashboard
- Secure JWT Authentication
- PostgreSQL Database Integration
- Docker Containerization

## 📋 Project Overview

KasBon is a comprehensive debt management system that allows users to:
- Register and authenticate securely
- Create and manage debt transactions
- Track payment status
- Admin dashboard for transaction oversight
- Secure payment verification system

## 🔧 Technical Stack

- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Authentication**: JWT
- **Containerization**: Docker
- **API Documentation**: Swagger/OpenAPI
